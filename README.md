# 👻 Offer Ghost 2.0

**Deal-Only Telegram Bot** - Finde die besten Supermarkt-Angebote automatisch!

## 🔥 Features

- 🎯 **Nur echte Deals** (min. 15% Rabatt)
- 📱 **Telegram-Bot** mit intuitiven Commands
- 🔔 **Push-Notifications** bei neuen Deals
- ⭐ **Favoriten-Tracking** für deine Lieblingsprodukte
- 🏪 **Multi-Store Support** (REWE, Lidl, Aldi Süd, Kaufland)
- 📊 **Smart Kategorisierung** (Obst, Getränke, Süßes, etc.)
- 🚀 **Docker-Ready** für einfaches Deployment

## 📋 Requirements

- Docker & Docker Compose
- Telegram Bot Token ([via @BotFather](https://t.me/botfather))
- Marktguru API Key (optional: OpenRouter für AI-Kategorisierung)
